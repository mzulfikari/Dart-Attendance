# ⚡ مدیریت حضور و غیاب نیروهای برق

**اپلیکیشن اندرویدی مدیریت حضور و غیاب نیروهای برق**، طراحی‌شده برای سرپرستان و مسئولان پروژه‌های برق، با تمرکز بر ثبت دقیق اطلاعات پرسنل، مدیریت روزانه حضور و غیاب و تهیه گزارش‌های کاربردی.

این اپلیکیشن با Flutter توسعه داده شده و با استفاده از دیتابیس محلی SQLite، بدون نیاز به اینترنت قابل استفاده است. رابط کاربری فارسی، تقویم شمسی و امکان خروجی گرفتن از گزارش‌ها، آن را برای استفاده در محیط‌های کاری و پروژه‌های اجرایی مناسب می‌کند.

---

## ✨ قابلیت‌ها

### 👷 مدیریت نیروها
- ثبت و ویرایش اطلاعات نیروها
- جستجو و دسترسی سریع به اطلاعات پرسنل
- فعال‌سازی و غیرفعال‌سازی نیروها
- ثبت مشخصات فردی، اطلاعات تماس و اطلاعات تماس اضطراری
- دسته‌بندی نیروها بر اساس سمت شغلی

### 📅 مدیریت حضور و غیاب
- انتخاب تاریخ با تقویم شمسی (جلالی)
- ثبت وضعیت حضور هر نیرو در روزهای کاری
- ثبت ساعت ورود و خروج
- امکان درج توضیحات برای هر رکورد
- پشتیبانی از پنج وضعیت حضور و غیاب:

| کد | وضعیت | توضیح |
|---:|---|---|
| 0 | حاضر | حضور عادی در محل کار |
| 1 | غایب | عدم حضور در محل کار |
| 2 | تأخیر | حضور با تأخیر |
| 3 | مرخصی | استفاده از مرخصی |
| 4 | مأموریت | حضور در مأموریت کاری |

### 📊 گزارش‌گیری و خروجی اطلاعات
- تهیه گزارش روزانه حضور و غیاب در قالب PDF
- تهیه گزارش ماهانه در قالب PDF
- خروجی Excel برای گزارش‌های ماهانه
- تهیه گزارش اختصاصی برای هر نیرو
- اشتراک‌گذاری فایل‌های گزارش

### 🌐 رابط کاربری فارسی
- پشتیبانی از زبان فارسی و چیدمان راست‌چین (RTL)
- استفاده از تقویم شمسی
- نمایش اعداد فارسی در رابط کاربری
- طراحی مبتنی بر Material Design 3

### 💾 ذخیره‌سازی آفلاین
- استفاده از SQLite برای نگهداری اطلاعات
- عملکرد بدون نیاز به اتصال اینترنت
- ذخیره محلی اطلاعات پرسنل و سوابق حضور و غیاب

> **نکته:** اطلاعات در دیتابیس محلی دستگاه نگهداری می‌شوند؛ بنابراین برای جلوگیری از ازدست‌رفتن داده‌ها، تهیه نسخه پشتیبان از اطلاعات اهمیت دارد.

## 🚀 راه‌اندازی پروژه

### پیش‌نیازها

برای اجرای پروژه به موارد زیر نیاز دارید:

- Flutter SDK نسخه سازگار با پروژه
- Dart SDK سازگار با نسخه Flutter
- Android SDK و ابزارهای ساخت اندروید
- Git

### ۱. دریافت مخزن

```bash
git clone https://github.com/mzulfikari/Dart-Attendance.git
cd Dart-Attendance/attendance_app
```

### ۲. نصب وابستگی‌ها

```bash
flutter pub get
```

### ۳. بررسی محیط توسعه

```bash
flutter doctor
```

### ۴. اجرای اپلیکیشن

برای اجرا روی دستگاه متصل یا شبیه‌ساز اندروید:

```bash
flutter run
```

### ۵. ساخت نسخه Release

برای تولید فایل APK قابل نصب:

```bash
flutter build apk --release
```

فایل خروجی در مسیر زیر قرار می‌گیرد:

```text
build/app/outputs/flutter-apk/app-release.apk
```

**نکته:** در صورت اجرای دستور از ریشه مخزن، ابتدا وارد پوشه `attendance_app` شوید. همچنین برای ساخت محلی اندروید، تنظیمات Android SDK و در صورت نیاز مسیر `flutter.sdk` در فایل `android/local.properties` باید صحیح باشد.

راهنمای تکمیلی ساخت پروژه در فایل [`BUILD_INSTRUCTIONS.md`](BUILD_INSTRUCTIONS.md) قرار دارد.

1. فایل `app-release.apk` را به گوشی منتقل کنید.

> فقط فایل APK را از منبع قابل اعتماد دریافت و نصب کنید.

## 🗄️ ساختار دیتابیس

اطلاعات اصلی برنامه در دو جدول `workers` و `attendance_records` نگهداری می‌شوند.

### جدول `workers`

اطلاعات نیروها و مشخصات تماس آن‌ها را ذخیره می‌کند.

| ستون | نوع | توضیح |
|---|---|---|
| `id` | INTEGER PK | شناسه یکتا |
| `name` | TEXT | نام و نام خانوادگی |
| `national_code` | TEXT UNIQUE | کد ملی |
| `phone` | TEXT | شماره تماس |
| `role` | INTEGER | سمت شغلی |
| `address` | TEXT | آدرس |
| `emergency_contact` | TEXT | نام مخاطب اضطراری |
| `emergency_phone` | TEXT | شماره تماس اضطراری |
| `created_at` | INTEGER | زمان ایجاد رکورد |
| `is_active` | INTEGER | وضعیت فعال یا غیرفعال |

مقادیر ستون `role`:

- `0` — تکنسین
- `1` — مهندس
- `2` — سرپرست
- `3` — کمک‌نیرو

### جدول `attendance_records`

سوابق حضور و غیاب نیروها را نگهداری می‌کند.

| ستون | نوع | توضیح |
|---|---|---|
| `id` | INTEGER PK | شناسه یکتا |
| `worker_id` | INTEGER FK | شناسه نیروی مربوطه |
| `date` | INTEGER | تاریخ ثبت‌شده به‌صورت timestamp برحسب میلی‌ثانیه |
| `status` | INTEGER | کد وضعیت حضور و غیاب |
| `note` | TEXT | توضیحات |
| `check_in_time` | INTEGER | زمان ورود |
| `check_out_time` | INTEGER | زمان خروج |
| `location` | TEXT | موقعیت مکانی ثبت‌شده |
| `created_at` | INTEGER | زمان ایجاد رکورد |

**ارتباط جداول:** هر رکورد حضور و غیاب به یک نیرو از طریق `worker_id` مرتبط است.

> نوع دقیق ذخیره‌سازی ساعت ورود و خروج، تاریخ و نحوه اعمال محدودیت‌های دیتابیس باید با پیاده‌سازی واقعی پروژه تطبیق داده شود.

## 🔄 ساخت خودکار APK

مخزن می‌تواند از GitHub Actions برای اجرای مراحل بررسی، تست و ساخت APK استفاده کند.

برای مشاهده وضعیت آخرین اجرا و دریافت خروجی:

1. وارد بخش [GitHub Actions](https://github.com/mzulfikari/Dart-Attendance/actions) شوید.
2. آخرین اجرای Workflow را باز کنید.
3. پس از موفقیت کامل فرایند، بخش **Artifacts** را بررسی کنید.
4. در صورت وجود Artifact با نام `attendance-apk`، آن را دریافت و فایل APK را از آرشیو استخراج کنید.

> وجود Artifact به موفقیت مرحله ساخت و بارگذاری آن وابسته است؛ صرف اجرای Workflow به معنای آماده‌بودن APK نیست.
